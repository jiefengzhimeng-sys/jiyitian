记一天 · V2 年轻化改版One Day · Design Direction

把每天记成一本手账，
而不是一张表单。

V1 是「蓝白卡片 + 灰色图标」的通用工具面孔——信息没错，但年轻人没理由在里面停留。V2 换掉整套视觉语言：奶油纸底替代冷灰背景，荧光青柠做签名色（高饱和、低明度面积占比，只在关键节点出现），标题字重拉到 800、字距收到 -0.03em，所有数字改用等宽字体——像手账上的日期戳，也像潮牌标签。阴影全部换成暖调（棕底而非灰底），去掉工业感。

签名色 Lime #D8F45C 纸底 #FAF6EF 圆角 8 / 16 / 22 / 26 字距 -0.03em 数字 Mono 触控 ≥ 44pt
Mood Scale · 情绪六档
开心 平静 低落 烦躁 焦虑 疲惫
六个色值全部经过对比度校验，与墨黑文字搭配均 ≥ 4.5:1；色相分布避开红绿对撞，对色弱用户仍可通过明度差区分。
